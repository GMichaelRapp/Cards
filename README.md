# Notecards

Personal notes, kept as plain Markdown files.

## How it works

- Open `notecards.html` in Chrome, Edge, or Brave.
- Choose the `notes/` folder in this repo. Every note is saved there as `Title.md`.
- Link notes with `[[Note Title]]`. Ctrl+E toggles preview, where links are clickable.
- Commit and push (GitHub Desktop works well) whenever you want a checkpoint.

## Notes

- Keep this repo out of iCloud, Google Drive, and Dropbox folders. Cloud sync and Git can conflict.
- The files are plain Markdown, so the `notes/` folder also opens in Obsidian or Trilium.
